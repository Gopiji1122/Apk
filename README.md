# Aura PDF Editor

100% Offline, Ad-Free Android PDF Editor built with Kotlin, Jetpack Compose, and PdfBox-Android.

- **App Name:** Aura PDF Editor
- **Application ID:** `com.gopiji1122.aurapdfeditor`
- **Internet Permission:** None (100% offline)

## How to Build APK via GitHub Actions
1. Extract this ZIP and push all files to your GitHub repository's `main` branch.
2. Open the **Actions** tab on GitHub.
3. Click the **Build Aura PDF Editor APK** workflow run.
4. Download **AuraPDFEditor-APK** from the Artifacts section and install on your Android device.
