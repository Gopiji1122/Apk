# Aura PDF Editor v4.0.0

100% Offline, Ad-Free Android PDF Suite (`com.aurapdf.editor`, `versionCode = 4`).

## Highlights in v4.0.0
- **Minimal Clean Home Screen:** Displays Recent PDFs directly under the **Aura PDF Editor** heading with zero clutter.
- **Left 3-Line Side Menu (`☰`):** Houses all tools (Open PDF, Scan, Blank PDF, Images to PDF, Word/Excel to PDF, Merge PDFs, and Theme Switcher).
- **Bottom-Right Floating `+` Speed Dial:** Opens upward with floating circular icons and text labels on the left (**Scan**, **Blank Page**, **From Image**).
- **Complete Document Scanner:** Camera + Gallery multi-page scanning, Magic Color / Grayscale / B&W Document filters, Rotate, Margin Trim, Save PDF, and **Edit PDF** button to send straight into the editor.
- **Interactive Edit PDF Studio:**
  - Add styled text in 10 colors, 3 font families (Sans/Serif/Mono), Bold/Italic/Underline/Highlight, and clickable links.
  - Add JPG/PNG images from gallery.
  - **Touch to Drag & Move** and **Corner Handle Touch Resize** for both images and text.
  - **Re-Editable Text Until Saved:** Tap any text box to edit its wording, color, font, or link before tapping **Save**.
  - **Upper Three-Dot Menu (`⋮`):** Direct access to Add Blank Page, Organize/Merge/Split Pages, Links Manager, Normal & Digital Signatures, Highlight & Redact, Custom Watermark, Password Lock/Unlock, Offline OCR, Compress/PNG Export, Night Mode, and Share.
