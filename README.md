# Aura Audio Player (Android)

100% offline music player. No internet permission, no ads, no tracking.

## Build the APK with GitHub Actions (no Android Studio needed)
1. Upload everything in this folder (the files, not the folder itself) to a GitHub repository, branch `main`.
2. Open the **Actions** tab. `Build Android APK` runs automatically (or press **Run workflow**).
3. When it finishes, open the run and download **ProMusicPlayer-release-APK** (or the debug one) from **Artifacts**.
4. Unzip it and install the `.apk` on your phone.

## Features
Library (songs, albums, artists, folders), playlists, favorites, smart lists (recent, most played, recently added),
search, queue, shuffle/repeat, playback speed, sleep timer, 5-band equalizer + bass boost, lock-screen and
notification controls, Bluetooth/headset buttons, resume last session, accent colors and AMOLED black theme.
